# Sandcastle Workflow

A private, independently versioned workflow package for deterministic GitHub-native issue implementation through Docker and Codex.

The package is distributed as a reviewed local npm tarball. It is not published to a package registry and does not expose a supported JavaScript or TypeScript import interface.
